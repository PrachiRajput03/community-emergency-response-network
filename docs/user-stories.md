# User Stories

## Citizen

### Registration

As a citizen, I want to create an account so that I can access emergency services.

### Login

As a citizen, I want to log in securely so that I can use the application.

### Create Emergency

As a citizen, I want to report an emergency so that nearby volunteers can be notified.

### Track Emergency

As a citizen, I want to see the status of my emergency request so that I know whether help is coming.

### View History

As a citizen, I want to view my previous emergency requests for reference.

---

## Volunteer

### Registration

As a volunteer, I want to register on the platform so that I can help people during emergencies.

### View Emergencies

As a volunteer, I want to view nearby emergency requests so that I can decide whether to respond.

### Accept Emergency

As a volunteer, I want to accept an emergency request so that the citizen knows help is on the way.

### Resolve Emergency

As a volunteer, I want to mark an emergency as resolved once assistance is provided.

---

## Administrator

### Monitor Emergencies

As an administrator, I want to view all emergency requests so that I can monitor system activity.

### Manage Users

As an administrator, I want to view registered users and volunteers.

### View Statistics

As an administrator, I want to view basic platform statistics such as total users and emergencies.
